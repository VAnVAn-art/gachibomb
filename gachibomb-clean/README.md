# Gachi Bomb & Gachi Ninja (HTML5 Standalone Edition)

Автономная версия игры на чистом HTML5 и Canvas, разработанная без использования сторонних движков.

## Основные возможности
1. Два режима игры:
   - Classic: классический режим с ловлей добавок, уклонением от бомб и прогрессивным нарастанием сложности.
   - Gachi Ninja: режим разрезания добавок свайпом клинка, системой комбо и 5 катанами с уникальными перками.
2. Фоновое онлайн-радио GachiRadio (gachiradio.com).
3. Адаптивный полноэкранный интерфейс под любые разрешения экранов (телефоны, планшеты, ПК) без черных рамок.
4. Встроенная защита от накрутки очков и интеграция с таблицей лидеров.
5. Магазин персонажей, катан и кейсы за игровую валюту.

## Запуск
Для локального запуска откройте `index.html` в браузере или запустите локальный веб-сервер в этой папке:
```bash
python -m http.server 8000
```
